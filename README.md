# 📱 English Learning App for Children using AI

> **[University Final Work]** An Android application that helps children learn English through AI-powered object recognition and handwriting detection.  
> 인공지능을 활용한 아동용 영어 교육 어플리케이션

---

## 📌 Overview

This is a gamified English learning app designed for children. Instead of passive study methods, the app encourages children to actively engage with learning through AI-driven interaction — recognizing real-world objects, listening to English words, speaking them aloud, and writing them by hand.

## 🎯 Objective

- Develop an educational app that moves children away from passive learning
- Allow children to **enjoy** the learning process through interactive gameplay
- Practice AI and database design in a real-world project setting

---

## 🔄 Learning Flow

```
1. Camera captures a real-world object
        ↓
2. TensorFlow Lite recognizes the object
        ↓
3. Child listens to and repeats the English word
        ↓
4. Child writes the word by hand
        ↓
5. Firebase ML Kit recognizes the handwriting
        ↓
6. Repeat for reinforcement learning
```

---

## ✨ Features

- **Object Recognition** — Identifies real-world objects via camera using TensorFlow Lite
- **Handwriting Recognition** — Validates handwritten English words using Firebase ML Kit
- **Story-based Gameplay** — Age-appropriate stories to keep children engaged
- **Repetition Learning** — Listen → Speak → Write cycle for effective vocabulary retention
